# Expanse Board Game

A collection of projects based on [The Expanse Board Game (2017, by Geoff Engelstein)](https://boardgamegeek.com/boardgame/220792/the-expanse-board-game). 
The board game is based on the [hit book series by James S.A. Corey](https://www.jamessacorey.com/books/leviathan-wakes/) and its [Syfy/Amazon TV adaptation](https://www.amazon.com/gp/video/detail/B0H49JXCSP).

Play it now! https://cmorley191.github.io/

- `expanse-model`: PyTorch machine learning model trained to identify the best moves available to a player in the board game
- `expanse-client`: WIP TypeScript UI where you will be able to play the 2-player version of the game against the AI model
